- Unit limitation: the raw CSV has no unit metadata. The experiment assumes the units displayed by the existing application (µg/m³ except CO in mg/m³). All calculated values and conclusions are conditional on this unverified assumption.
- This is a CPCB-style calculation using the project's standalone calculator and cited breakpoint rules. It does not establish that the source dataset is official CPCB data.
- Comparison grain: location-day. Original AQI is the arithmetic mean of that day's supplied hourly AQI, matching project preprocessing.
- PM2.5/PM10/NO2/SO2 use the daily 24-hour mean. CO/O3 use the maximum complete trailing 8-hour mean ending within the calendar day; no single-hour O3/CO value is used as an 8-hour average.
- A pollutant daily value requires at least 16 valid non-negative hourly observations. Eight-hour means additionally require eight consecutive hourly observations. Calculator-unresolved cases, including O3 above its validated 8-hour range, are excluded.
- Category mapping uses CPCB AQI bands; unrounded float AQI values are retained, following the calculator.
- Same-hour raw AQI/pollutant Pearson correlations: PM2.5 r=0.9621, PM10 r=0.9331, NO2 r=0.1937, SO2 r=0.5686, CO r=0.1766, O3 r=0.2007. This shows association (strongest with particulate concentrations here), not the formula or provenance used to produce the supplied AQI.

F. Implication for ML forecasting
- Existing forecasting targets use the source AQI and should be interpreted as forecasts of that source-defined target, not as validated CPCB AQI forecasts.
- If agreement is poor or partial, the existing target embeds a different AQI semantic from the CPCB-style concentration-based index. Do not silently relabel it as CPCB AQI. Any future switch to a CPCB-derived target should be a separately reviewed dataset and model experiment; this validation did not retrain models.
- Even high agreement would remain conditional on undocumented source provenance/units, this dataset's physical-consistency issues, and the chosen daily 8-hour maximum convention; that calendar-day summary choice is not independently established here as a mandatory CPCB daily aggregation rule.

Daily aggregation assessment
- The current 24-hour arithmetic mean of source AQI is reproducible and was used for an apples-to-apples comparison with the existing project target. It is not mathematically equivalent in general to calculating AQI from daily pollutant means because interpolation and the maximum-pollutant rule are nonlinear.
- For CPCB-style daily comparison, 24-hour pollutant means and within-day maximum complete 8-hour CO/O3 averages are more methodologically aligned than calculating from a single hourly pollutant record. The source AQI's own averaging/provenance is undocumented.
