The training targets are direct horizons: each feature row at date t is used
to predict AQI_t+1, AQI_t+2, and AQI_t+3. Thus the three horizon models each
expect features constructed at the same observed origin date t. Their target
dates are t+1, t+2, and t+3; future calendar values are not input features in
the training contract.

2. EXACT TRAINING FEATURE DEFINITIONS
-------------------------------------
AQI, lag, and rolling construction is performed independently within each
location after sorting by location_name and date:

- aqi: observed daily AQI at the feature row date t.
- AQI_lag_1: aqi.shift(1), AQI at t-1.
- AQI_lag_2: aqi.shift(2), AQI at t-2.
- AQI_lag_3: aqi.shift(3), AQI at t-3.
- AQI_rolling_mean_3: aqi.shift(1).rolling(window=3, min_periods=1).mean().
  The current row AQI[t] is excluded; available previous rows are used.
- AQI_rolling_mean_7: aqi.shift(1).rolling(window=7, min_periods=1).mean().
  The current row AQI[t] is excluded; available previous rows are used.
- AQI_rolling_std_7: aqi.shift(1).rolling(window=7, min_periods=2).std().
  The current row AQI[t] is excluded. pandas .std() uses sample standard
  deviation (ddof=1).
- pm25, pm10, no2, so2, co, o3: daily pollutant values at date t from the
  historical daily dataset.
- month: date t month, 1-12.
- day: date t day of month, 1-31.
- day_of_week: date t weekday, Monday=0 through Sunday=6.
- is_weekend: 1 when date t weekday is Saturday or Sunday, otherwise 0.
- loc_Delhi, loc_Faridabad, loc_Ghaziabad, loc_Gurgaon, loc_Noida: one-hot
  indicators for the row's location_name, in the exact model order below.

Feature-engineering code creates direct targets with groupby(location_name)
and negative shifts. The targets do not turn inference into a recursive
forecast; each horizon has its own separately trained direct model.

4. MISMATCHES FOUND
-------------------
1. The model set is direct-horizon, but inference recursively appended the
   Day+1 prediction before constructing Day+2 inputs and the Day+2 prediction
   before constructing Day+3 inputs. This changed aqi and lag features away
   from the feature row on which each direct model was trained.
2. Rolling means included the latest observed/current or recursively
   predicted AQI instead of applying training's shift(1) first.
3. Rolling standard deviation used population ddof=0, while training's
   pandas rolling .std() uses sample ddof=1. The calculation also used the
   wrong, unshifted recursive window.
4. Calendar features used each target date t+h. Training uses calendar
   values from the feature/origin row date t. For direct horizon models,
   target date is output metadata, not a replacement calendar feature row.
5. Old short-history fallback values silently substituted latest AQI for
   missing lag history. The corrected code fails clearly unless the three
   required prior AQI records exist.

5. CHANGES MADE
---------------
- Added src/forecast_features.py with the canonical ordered 22-column
  feature contract and a training-equivalent origin-row builder.
- The rolling feature calculations now use shift(1), rolling windows and
  min_periods exactly as preprocessing does. Rolling std is sample std
  (ddof=1), not population std.
- app.py now creates one observed-origin vector and passes that same vector
  independently to rf_day1, rf_day2, and rf_day3. Future actual AQI is never
  read; model predictions are outputs only and are not recursively fed back.
- Future forecast dates remain origin date plus 1, 2, or 3 days. For exact
  training consistency, all direct horizon feature vectors retain calendar
  fields for the observed origin date t.
- The inference path verifies saved-model feature_names_in_ (when available)
  and n_features_in_ before prediction. The vector is explicitly ordered and
  must contain exactly 22 predictors.
- Historical daily pollutants are held at the latest observed origin day as
  the training contract requires. No WAQI values are read or used.

7. WORKED DAY +1 EXAMPLE
------------------------
Suppose the latest observed origin day t has AQI[t]=70 and the previous
observations are AQI[t-1]=60, AQI[t-2]=50, and AQI[t-3]=40.

The training-equivalent Day +1 feature row uses:
  AQI_rolling_mean_3 = mean(AQI[t-1], AQI[t-2], AQI[t-3])
                     = mean(60, 50, 40)
                     = 50

AQI[t]=70 is not included in this rolling mean. The aqi feature itself is 70;
the rolling feature is exclusively backward-looking.
